# 知径 · 产品需求文档（PRD）

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品 | 知径 |
| 版本 | MVP 1.0 |
| 日期 | 2026-09-13 |
| 目标 | 完成“输入话题 → 生成知识地图 → 阅读资源 → 记录进度”闭环 |

## 2. 产品范围

### 2.1 本版本包含

首页、话题生成、地图画布、资源展开、知乎跳转、进度记录、一级下钻、错误与降级状态、三个预生成话题。

### 2.2 本版本不包含

节点编辑、笔记批注、多地图管理、协作、收藏夹导入和移动端专门布局。

## 3. 信息架构

```text
首页
├── 预生成话题
├── 话题输入
└── 最近访问（可选）

地图页
├── 顶部导航与面包屑
├── 话题总览
├── 学习进度
├── React Flow 地图
├── 节点资源卫星圈
└── 节点操作菜单
```

## 4. 核心用户流程

### 4.1 预生成话题

1. 用户进入首页。
2. 点击“微积分”“Python 入门”或“摄影”。
3. 前端读取缓存地图。
4. 地图页直接展示完整节点和资源。

### 4.2 实时生成

1. 用户输入话题并提交。
2. 前端校验输入非空并去除首尾空格。
3. 服务端归一化话题并查询缓存。
4. 命中缓存则直接返回；未命中则调用直答生成大纲。
5. 前端先渲染总览和灰色节点骨架。
6. 服务端并发检索各节点资源。
7. 每个节点资源返回后，前端逐个点亮节点并更新大小。
8. 全部完成后写入地图缓存。

### 4.3 阅读资源

1. 用户点击知识点节点。
2. 节点周围展开最多 3 个资源卫星圈。
3. 每个卫星圈展示标题、作者、赞数和评论数。
4. 用户点击资源后新标签打开知乎原文。
5. 该知识点标记为已学，顶部进度同步更新。

### 4.4 一级下钻

1. 用户打开知识点菜单。
2. 点击“以此为中心展开”。
3. 服务端以该知识点标题或搜索词生成最多一层子地图。
4. 地图页替换为子地图并更新面包屑。
5. 用户点击上级面包屑返回原地图。

## 5. 页面需求

### 5.1 首页

必须包含：

- 产品名称与一句话定位。
- 三张预生成话题卡片。
- 话题输入框和提交按钮。
- 输入为空、过长或请求失败时的提示。

验收：

- 点击预生成话题可进入地图页。
- 输入有效话题后进入生成状态。
- 提交期间按钮防重复点击。

### 5.2 地图页

必须包含：

- 话题名称。
- 总览：这是什么、学完能做什么、预计用时。
- 进度：已浏览知识点数 / 总知识点数。
- 三层地图：入门、进阶、深入。
- 返回首页和面包屑。
- 缩放、平移、拖动节点。

视觉规则：

- 画布使用米白背景。
- 入门、进阶、深入分别使用柔绿、柔蓝、柔紫。
- 节点半径按 top3 资源权重之和映射到 40–90px。
- 主线使用实线粗箭头，支线使用虚线细箭头。
- 待加载节点为灰色空心圈并有呼吸动画。
- 已学节点降低饱和度并显示勾选角标。

### 5.3 节点与资源

节点必须展示标题和简短摘要；资源卫星圈必须展示标题截断、作者、赞数和评论数。

节点状态：

| 状态 | 展示 | 可操作 |
|---|---|---|
| pending | 灰色空心圈、加载动画 | 不可打开资源 |
| ready | 按权重着色和缩放 | 展开资源、下钻 |
| empty | 虚线灰圈、无优质资料 | 跳知乎站内搜索、重试 |
| error | 错误标识 | 单节点重试 |
| retrying | 加载动画 | 禁止重复重试 |

### 5.4 资源跳转

- 使用新标签打开知乎原文。
- 页面标注“来源：知乎”。
- 不在本产品内展示完整文章正文。
- 跳转成功后将知识点写入浏览器 localStorage。

## 6. 接口需求

### 6.1 `POST /api/outline`

请求：

```json
{ "topic": "微积分" }
```

成功响应应包含：

```json
{
  "topic": "微积分",
  "overview": {
    "what": "string",
    "gain": "string",
    "duration": "string"
  },
  "nodes": [
    {
      "id": "string",
      "title": "string",
      "level": 1,
      "summary": "string",
      "query": "string"
    }
  ],
  "edges": [
    { "from": "node-a", "to": "node-b", "type": "main" }
  ]
}
```

约束：

- 节点数 6–10 个。
- 至少覆盖入门、进阶、深入三层。
- 节点 ID 唯一。
- 边的起点和终点必须存在。
- 不允许形成环。
- 非学习类话题返回 `not_learnable`。
- 非法 JSON 自动重试 1 次。

### 6.2 `POST /api/resources`

请求：

```json
{ "topic": "微积分", "nodeId": "limits", "query": "微积分 极限 入门" }
```

响应：

```json
{
  "nodeId": "limits",
  "state": "ready",
  "resources": [
    {
      "title": "string",
      "url": "string",
      "contentId": "string",
      "contentType": "string",
      "author": "string",
      "voteUpCount": 0,
      "commentCount": 0,
      "excerpt": "string",
      "editTime": 0,
      "score": 0
    }
  ]
}
```

最多返回 3 条资源。无结果返回 `empty`，调用失败返回错误码。

### 6.3 `GET /api/map`

按归一化话题读取 24 小时内缓存的地图。缓存不存在或过期时返回未命中状态。

### 6.4 SSE 事件

推荐事件：

```text
outline
resource_ready
resource_empty
resource_error
complete
```

每个事件必须带 `nodeId`（全局事件除外），前端按事件幂等更新，不因单个事件重复而产生重复节点。

## 7. 排序与数据规则

候选资源先经过相关性和内容类型过滤，再按以下逻辑计算：

```text
engagement = log(1 + voteUpCount)
            + 0.5 * log(1 + commentCount)
            + authorityWeight

score = 0.6 * normalizedRankingScore
      + 0.4 * normalizedEngagement
```

`authorityWeight` 仅对已建立映射的认证等级生效，未知等级按 0 处理。资源汇总、广告和明显不相关内容默认过滤；必要时可单独展示资源推荐区域。

## 8. 数据模型

### 8.1 `maps`

- `key`：归一化话题，唯一。
- `topic`
- `overview`
- `nodes`
- `edges`
- `generatedAt`
- `expiresAt`

### 8.2 `quota`

- `date`
- `outlineCount`
- `resourceCount`
- `updatedAt`

## 9. 非功能需求

- 所有知乎接口调用只发生在服务端。
- API 密钥不得进入前端响应、客户端代码或日志。
- 搜索并发度最多为 5。
- 页面不能因单个资源请求失败而整体不可用。
- 地图节点拖动、缩放和平移不能导致布局抖动。
- 关键按钮、输入框和节点操作支持键盘访问。
- 桌面端优先，窄屏下不得发生严重遮挡或横向溢出。

## 10. 异常与降级

| 场景 | 用户看到的结果 |
|---|---|
| 话题为空 | 提示输入学习话题 |
| 非学习类话题 | 提示更换为可学习的领域或技能 |
| 大纲失败 | 提示暂时无法生成，并保留重新生成入口 |
| 单节点无结果 | 显示“社区暂无优质资料”，可跳知乎搜索 |
| 单节点报错 | 显示重试按钮，不阻塞其他节点 |
| 额度耗尽 | 提示今日实时生成额度已用完，仍可打开缓存地图 |
| 高风险主题 | 展示不替代专业意见的风险提示 |

## 11. 埋点与观测

首版至少记录服务端指标，不记录敏感凭证：

- 话题生成请求数、成功数和失败原因。
- 直答耗时、搜索耗时和整体生成耗时。
- 缓存命中率。
- 节点资源为空和重试比例。
- 预生成话题打开次数。

前端可选记录：

- 话题提交。
- 节点展开。
- 资源点击。
- 下钻进入与返回。
- 节点完成。

## 12. 开发拆分

1. 项目脚手架、环境变量和知乎服务端客户端。
2. 话题归一化、缓存和额度计数。
3. 大纲接口、JSON 清洗、校验和重试。
4. 资源搜索、过滤、排序和节点状态。
5. 地图布局、节点、边和交互。
6. SSE 增量更新与加载状态。
7. 资源卫星圈、知乎跳转和进度。
8. 一级下钻、面包屑和预生成地图。
9. 异常状态、风险提示、线上部署和端到端走查。

## 13. 验收清单

- [ ] 三个预生成话题可以打开完整地图。
- [ ] 新话题能生成 6–10 个节点并展示三层结构。
- [ ] 地图可缩放、平移和拖动。
- [ ] 节点资源能逐个加载并按权重改变大小。
- [ ] 点击节点可展开和收起最多三个资源。
- [ ] 点击资源在新标签打开知乎原文。
- [ ] 返回后对应节点显示已学，进度数字更新。
- [ ] 可从节点进入一级下钻，并通过面包屑返回。
- [ ] 单节点失败、空结果和额度耗尽均有明确状态。
- [ ] 用户刷新页面后本地进度仍存在。
- [ ] 生产环境凭证未暴露，核心流程可公网访问。
